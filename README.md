# Проект "The_banking_operations_widget"

## Описание

Проект "The_banking_operations_widget" — виджет банковских операций клиента.
Маскирует номера карт и счетов, форматирует даты, фильтрует и сортирует
операции по статусу и дате.
Присутствуют генераторы, фильтрующие поступающие транзакции по указанной валюте, выдающие описания выбранного диапазона 
транзакций, создающие уникальные номера банковских карт. 
Присутствует декоратор, позволяющий собирать отчеты о работе функций всех модулей проекта в файл
Помимо JSON, проект поддерживает загрузку финансовых операций из **CSV** и **Excel** (`.xlsx`). 
Для этого в модуле `src/file_readers.py` реализованы отдельные функции, которые используют библиотеку `pandas`.

## Поиск и статистика по операциям

В модуле `src/processing.py` добавлены функции для анализа транзакций с использованием стандартных библиотек `re` и `collections`.

### Поиск по описанию
Функция `process_bank_search(data, search)` ищет операции, в описании которых есть заданная строка.
Поиск работает **без учета регистра** (регистр не важен) и использует регулярные выражения (`re`).

## Требования

- Poetry — для управления зависимостями. Список зависимостей — в `pyproject.toml`.
