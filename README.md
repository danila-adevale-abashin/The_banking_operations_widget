# Проект "The_banking_operations_widget"

## Описание:

Проект "The_banking_operations_widget" - Это виджет банковских операций клиента.

### Требования:

- Python 3.14+
- Poetry (для управления зависимостями). Список всех зависимостей находится в pyproject.toml

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/danila-adevale-abashin/The_banking_operations_widget.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. На данный момент используется только для код-ревью наставником.
