# Проект "The_banking_operations_widget"

## Описание

Проект "The_banking_operations_widget" — виджет банковских операций клиента.
Маскирует номера карт и счетов, форматирует даты, фильтрует и сортирует
операции по статусу и дате.

## Требования

- Python 3.14+
- Poetry — для управления зависимостями. Список зависимостей — в `pyproject.toml`.

## Установка:

1. Клонируйте репозиторий:
```
git clone https://github.com/danila-adevale-abashin/The_banking_operations_widget.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. На данный момент используется только для код-ревью наставником.


## Тесты

Тесты написаны на `pytest`. Установлены в группу `dev`.

Запуск тестов:
`poetry run pytest`

Запуск с покрытием:
`poetry run pytest --cov=src --cov-report=term-missing`
